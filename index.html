Se modela el reajuste del presupuesto de un proyecto de software en cuatro categorías como el sistema simétrico definido positivo Ax = b, y se resuelve con Cholesky (referencia), GC simple y GCP (Suñagua, 2020), en tres escenarios. Todo se recalcula al editar los datos.

1. Caso de estudio y formulación

Una empresa de software planifica un proyecto con presupuesto en miles de USD. Cada categoría compite por recursos compartidos (personal, nube, tiempo del calendario). El desvío óptimo de cada categoría respecto de su línea base se obtiene minimizando el costo cuadrático f(x) = ½ xᵀAx − bᵀx, cuyo mínimo cumple Ax = b. Esto exige A simétrica y definida positiva (SPD).

Variables (miles de USD asignados): x₁ = Desarrollo (backend y frontend), x₂ = Pruebas y QA, x₃ = Infraestructura cloud, x₄ = Seguridad y DevOps.

Coeficientes: aii es el peso de costo propio de la categoría i (mayor valor = el costo crece más rápido al asignar). aij = aji es el acoplamiento por recursos compartidos entre i y j (por ejemplo QA depende de Desarrollo e Infraestructura). bi es la demanda presupuestaria objetivo de la categoría i según el plan del proyecto.

Los datos son un modelo ilustrativo construido para el desafío, no datos reales de una empresa; los pesos se justifican por la estructura típica de dependencias entre áreas de un proyecto de software.
